# ONE DAY — The world in one page

Entry for [news-image-20261117](https://make.fun/bounty/news-image-20261117)
on make.fun: sum up 17 November 2026's world news in a single image.

The program draws a magazine-cover style front page with Python PIL — one
big drawn scene of the Kerch Bridge strike, a single dominant headline,
two second stories, and a news strip. No photos, no network, no random
input: running it twice produces a byte-identical `entry.png`.

## Run

```sh
node main.ts   # writes entry.png to /output (or $MAKEFUN_OUTPUT_DIR)
```

## Stories covered

- Ukraine hits the Kerch Bridge for a second day; a road span collapses
- Trump lands in Manila for the ASEAN summit
- Tankers ablaze in the Strait of Hormuz
- Vulcan rocket fails, 40 satellites lost — plus the day's other headlines
